# PHASE 1.1 图片资源与来源记录

全部人物和食物视觉均为本对话内置生成工具制作的原创虚构素材，不是知名运动员照片或真实用户记录，不表达人物代言。未使用Nike/Adidas广告或商标，未购买图库、开发者服务或外部图像API额度。

尝试访问Pexels/Unsplash素材与许可页时遇到网络策略403，未将未核实的第三方图片投入使用。

生成记录：1张主视觉、3张四场景底稿，另对单车底稿做一次去除伪文字的清理。各运动场景分别导出独立文件，不将同一照片重复充当11项运动。原始PNG保留于工作区generated_images，Web工程只交付本地WebP。

内置生成能力并非项目内付费API；未使用用户的图像API Key或开通付费服务。本会话工具/订阅本身的计量未从环境获得，不声称整个平台零费用。

权利说明：没有第三方摄影许可或明星肖像授权；主体是虚构成年人。生成素材不保证在所有司法地区具有排他版权，不伪造授权证书。正式商业发布前可按运营地区复核相关条款。
