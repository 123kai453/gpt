# 变更记录

## 2026-11-03 — FITNESS OS 2.0需求基线
- 保留多用户、私人空间、公开分享。
- 保留Apple/Linear视觉、3D、粒子、PWA。
- 保留力量、游泳、营养、食品记忆、AI多模型和长期记忆。
- 新增运动中心：户外跑步、跑步机爬坡、室内动感单车、徒步/登山、椭圆机、划船机、跳绳、登山机和其他运动。
- 新增GPS与手动双模式。
- 新增食品多图包装导入。
- 新增长文本训练/饮食/运动计划及图片/文档智能导入。
- 新增Apple Watch/Apple Health与华为手表/Huawei Health设备接入架构，实际连接后续实施。
- 明确纯Web/PWA不能直接调用Apple HealthKit；需原生iOS桥接。
- 初期低成本，设备和AI付费能力按需启用。

每次后续更新记录日期、文件、原因、影响、数据库迁移和测试结果。
