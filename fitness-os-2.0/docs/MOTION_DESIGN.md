# FITNESS OS PHASE 1.1 动效规范

- Hero：仅宽屏细指针设备启用，指针视差最大约6px横向/4px纵向；滚动位移最多32px，spring平滑，不按每帧更新React state。
- 主标题：两层进入约700ms，错开约110ms；英文与辅助文案后进入，主标语固定不随机。
- 环境：6个低对比粒子、16秒慢光线变化；无WebGL、无视频、无快速闪烁和旋转。
- 运动卡片：hover上移5px、图片放大1.045、边缘柔光；active轻微缩放，真实Link导航。
- 页面：进入位移5px/220ms；选中导航使用共享layoutId平滑过渡。
- 模块：AI/设备/身体使用装饰性CSS空间球体与轨道，不显示虚构健康数据或图表。真实图表绘制仍待后续真实数据。
- 手机：禁用人物视差、滚动位移和粒子，停掉装饰节点循环，只保留克制的标题/页面进入。
- prefers-reduced-motion：关闭视差、粒子、循环光效/节点与卡片变形；页面进入不设初始位移。
- 性能验收：在当前Chromium记录帧间隔样本，和真实手机性能分开报告；不以一次桌面采样保证所有设备60fps。
