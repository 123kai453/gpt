# 开发阶段与交付物

PHASE 0：环境检查、Web与原生边界、Apple/Huawei可行性、数据库实体、RLS、成本和风险报告。未经确认不生成大量业务代码。

PHASE 1：Next.js基础、设计系统、响应式页面、Dashboard、PWA骨架。

PHASE 2：Supabase Auth、迁移、RLS、多用户隔离、资料、云端同步、数据导出。

PHASE 3：力量动作库、计划自主编辑/版本、训练记录、游泳和通用运动中心、专属指标、手动记录。

PHASE 4：GPS前台记录、路线隐私、轨迹质量过滤；说明PWA后台限制。

PHASE 5：食品多图导入、OCR、商品档案、食物标签、营养计算。

PHASE 6：长文本训练/饮食/运动计划导入，图片/截图/文档解析，预览确认和防覆盖。

PHASE 7：Multi AI Provider、长期记忆、训练/运动/营养分析、预算熔断。

PHASE 8：可穿戴统一接口、模拟器、文件导入回退；Apple原生桥接和Huawei官方接入条件评估。设备实际连接后续启用。

PHASE 9：3D人体、粒子、按需食物3D。

PHASE 10：单元、集成、端到端、多用户安全、同步、GPS、导入、AI成本、设备数据去重测试；部署和备份恢复。

每阶段报告已完成、未完成、测试证据、风险、费用和下一步。
