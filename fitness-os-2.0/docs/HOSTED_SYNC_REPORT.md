后续两个浏览器会话只能证明浏览器会话同步；手机视口不算真实手机硬件。私人路径不缓存 HTML，离线刷新可能显示浏览器网络错误；已打开且会话有效时才能离线编辑。不会为了验收将健康数据放入公共 Service Worker 缓存。
