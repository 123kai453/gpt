## 只读审查后才能确定的分支

| 观察结果 | 推荐动作 |
|---|---|
| 目标身份确认、无同名对象/冲突策略、版本未应用 | 完成备份/恢复计划，给出实际差异与影响，等待用户确认后执行现有迁移 |
| 版本已记录且 SQL/实际对象完全匹配 | 不重复应用 CREATE；核对所有对象与权限后转验收 |
| 有对象但缺少/不一致的迁移历史 | 暂停，逐项审查来源，不能自动补记版本或删对象 |
| 同名表/app_private/函数/触发器/不兼容桶 | 暂停，不覆盖现有数据或更换成另一套迁移 |
| storage.objects 已有其他策略 | 现有 SQL 会主动中止；审查 OR 组合和其他桶影响，不绕过保护 |
| 版本/结构/数据来源无法确认 | 保持 BLOCKED，不把项目当作空数据库 |
