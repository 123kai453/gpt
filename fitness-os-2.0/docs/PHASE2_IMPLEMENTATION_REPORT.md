## 4. 安全设计

公开 key 仅有匿名/用户权限；service_role/secret 只在服务端账户最终删除步骤使用。RLS、严格字段白名单和 SQL 校验同时阻止伪造 user_id、版本及归属。回调返回路径有严格白名单与 PKCE flow 绑定；写接口校验 Origin、Content-Type、请求大小和输入。认证及私人响应 `no-store`，图片下载包含附件、nosniff 与 CSP。应用处理函数不记录密码、密钥、令牌或原始健康数据。

限流使用 PostgreSQL 原子计数，资料 RPC 自身限流，不依赖单进程内存。媒体、导出与授权 API 分别限流。原生 Storage 路径执行归属、MIME 声明和单文件上限，真实字节校验属于账户上传接口；不把原生 Storage 的 MIME 检查描述为深度图片扫描，也未实现每用户总存储配额。

完整说明见 [SECURITY_AND_RLS_REPORT](SECURITY_AND_RLS_REPORT.md)、[DATABASE_SCHEMA](DATABASE_SCHEMA.md)、[SYNC_ARCHITECTURE](SYNC_ARCHITECTURE.md)。
