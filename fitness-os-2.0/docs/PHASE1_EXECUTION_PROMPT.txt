## 五、视觉设计：这是本阶段的重点

我希望 FITNESS OS 具有独立的产品审美。

参考 Apple 官网、Linear、现代运动健康类产品的设计理念。

注意：只借鉴设计语言，不直接复制其他网站的布局、图片或受保护素材。

### 1. 整体风格

关键词：

- 极简。
- 高级。
- 科幻感。
- 专业运动科技。
- 清晰的数据层次。
- 精致的微交互。
- 适度的未来感。

避免：

- 普通后台管理系统的廉价感。
- 大面积廉价渐变。
- 过度玻璃拟态。
- 过多装饰性卡片。
- 密集的数字和文字。
- 没有意义的动画。

### 2. 主题

默认深色模式。

同时支持浅色模式。

建立统一设计变量：

- 主背景。
- 次级背景。
- 卡片背景。
- 主文字。
- 次级文字。
- 强调色。
- 边框。
- 阴影。
- 圆角。
- 间距。
- 字体层级。

主题切换必须真实可用，并记住用户选择。

### 3. 桌面端

采用：

左侧导航栏 + 中央内容区域 + 必要时的辅助信息区域。

布局要充分利用宽屏，不要把所有内容挤在中央一个窄卡片里。

### 4. 手机端

采用独立的移动端布局：

- 顶部品牌区域。
- 清晰的内容层级。
- 底部导航。
- 合理的触控区域。
- 适应不同手机屏幕。
- 不允许横向溢出。
- 表格和图表需要适配小屏幕。

桌面端和手机端必须是同一套产品，不是两个独立的网站。

### 5. 品牌

正式使用 FITNESS OS 名称。

建立统一的文字标识、图标、配色和视觉规范。

不要随意使用版权不明的图片。
