# 编码规范
1. TypeScript优先，避免any。
2. 页面、业务逻辑、数据访问和AI适配层分离。
3. 所有输入客户端/服务端验证。
4. 所有写入检查身份、所有权和业务约束。
5. RLS必须有自动化或手动测试证据。
6. 组件有加载、空、错误、成功状态。
7. 不允许空按钮、死链接、假交互。
8. 不硬编码密钥；设备令牌只在服务端安全存储。
9. 测试数据标注demo/seed，不混入真实用户数据。
10. 计划修改不能覆盖历史训练。
11. AI输出通过Schema校验，标注用户输入/程序计算/估算/推导。
12. 文件校验类型、大小、恶意内容风险和权限。
13. GPS精确路线默认私人。
14. 可穿戴同步必须幂等、去重、支持断连和撤权。
15. 不支持的设备指标显示不可用，不编造。
16. 新增依赖说明用途；每次任务运行测试并更新文档。
