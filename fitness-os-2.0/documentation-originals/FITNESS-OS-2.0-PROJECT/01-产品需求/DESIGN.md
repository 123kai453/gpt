# 视觉与交互规范

方向：Apple的克制与清晰 + Linear的数据密度 + 局部科幻3D。不得直接复制受保护界面。

- 深色默认、浅色可选；统一设计token。
- 数据优先可读性，图表有单位、时间范围和来源。
- 桌面侧栏导航；手机底部导航或简洁抽屉。
- 运动中心使用统一运动卡片，但记录表单按运动类型动态变化。
- 食品多图导入提供图片集合、识别进度、字段校验和确认预览。
- 长文本导入提供原文区、解析结果区、未识别字段提示和确认按钮。
- 设备中心显示未连接/待授权/已连接/同步失败/最后同步时间；不得伪造已连接状态。
- GPS运动页必须明确显示定位授权、定位精度、记录状态和隐私提示。
- 动效克制、可关闭，支持prefers-reduced-motion。
- 手机端降低粒子数量和3D复杂度。
- 重要删除、公开分享、设备授权和付费AI/3D调用必须二次确认。
