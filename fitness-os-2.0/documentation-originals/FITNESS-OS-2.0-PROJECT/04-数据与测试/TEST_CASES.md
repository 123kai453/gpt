# 验收测试

## 用户和安全
- [ ] A/B用户私人数据隔离。
- [ ] GPS、睡眠、心率默认私人。
- [ ] 用户撤权后设备停止同步。
- [ ] 分享计划不泄露私人路线和健康指标。

## 力量计划
- [ ] 用户可完全手动创建计划。
- [ ] 长文本“卧推35 3*10”解析正确。
- [ ] 解析预览允许编辑；未确认不导入。
- [ ] 修改计划不覆盖历史记录。

## 运动
- [ ] 首批运动类型均可创建记录。
- [ ] 不同运动显示对应指标。
- [ ] 手动记录可用。
- [ ] GPS需授权，前台路线记录正常。
- [ ] GPS漂移点过滤；暂停/继续/结束正常。
- [ ] 不宣称PWA锁屏后台GPS必然可用。
- [ ] 游泳出发间隔、休息和游进时间区分。

## 食品多图
- [ ] 多张图片关联同一商品。
- [ ] 正面、配料表、营养表字段来源可追溯。
- [ ] 每100g/100ml/每份/整包装不混淆。
- [ ] kJ/kcal转换正确。
- [ ] 未标注营养素不自动编造。
- [ ] 用户确认前不写入正式食品库。
- [ ] 同名不同品牌/规格可区分。

## 长文本与文件导入
- [ ] 整周训练计划识别。
- [ ] 饮食计划识别。
- [ ] 多运动记录识别。
- [ ] 图片/截图/支持的文档解析。
- [ ] 原文保留、字段置信度/待确认标记。
- [ ] 未确认不覆盖已有计划。

## AI
- [ ] 无Key时手动记录和程序计算可用。
- [ ] Provider调用真实可测。
- [ ] Key不进入前端。
- [ ] 预算熔断有效。
- [ ] AI计划修改需确认。
- [ ] 记忆可查改删。

## 设备
- [ ] 未连接时显示真实未连接状态。
- [ ] Apple HealthKit桥接被明确标记为需要原生iOS companion。
- [ ] Huawei连接能力按官方权限和设备能力显示。
- [ ] 重复同步不重复计数。
- [ ] 设备数据来源和单位保留。
- [ ] 无数据权限时不编造数据。

## 同步和发布
- [ ] 手机/电脑同步。
- [ ] 离线队列和冲突处理。
- [ ] 数据导出、删除和备份恢复。
